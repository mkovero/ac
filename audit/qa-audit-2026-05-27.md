## critical gaps

These are cases where a measurement can be wrong and **no test would catch it**:

1. **THD+N denominator is the fundamental, not total signal level** (`thd.rs:118`, `thd.rs:107`).
   Both AES17-2020 §6.3.1 and IEC 60268-3 §15.12.3.2 (the clause the file *cites*)
   reference the ratio to the **total** signal. Every THD test feeds a pure or
   near-pure sine where fundamental≈total, so the divergence is structurally
   untestable by the current suite. A DUT with several-% THD+N will read low.
   The file's doc comment claims it is "bit-compatible" with §15.12.3.2 — that
   claim is inaccurate on the denominator.

2. **No producer↔consumer schema test for the ZMQ session frames.**
   `ac-daemon/handlers/audio/monitor.rs` emits `momentary_lkfs` / `integrated_lkfs`
   / `dBTP` / THD JSON; `ac-ui/data/types.rs` deserializes it. Nothing asserts the
   two agree. A renamed field on either side compiles clean and fails silently at
   runtime. (The qa-spec's "does `ds` parse what `ac` publishes" concern is moot —
   `ds` reads CSV/config files, not ZMQ — but the **ac-daemon→ac-ui** contract is
   the real instance of that risk and is untested.)

3. **CCIR-468 quasi-peak detector unverified against BS.468-4 Table 2.**
   `ccir468.rs:191-195` time constants are hand-picked. The weighting curve is
   exact, but a wrong QP ballistic would produce an incorrect 468-weighted noise
   figure that the steady-state-only tests cannot detect. Highest-value missing
   test: assert the QP reading for 5ms/10ms/100ms tone bursts against the Table 2
   relative-level tolerances.

4. **`ds` has zero tests** and two uncaught network failure modes
   (`ai.py`/`scraper.py` catch only `HTTPError`; `URLError`/`socket.timeout` crash
   with a raw traceback; `call_claude` has no timeout). No prompt caching despite
   re-sending full session context on every `analyze`/`ask`/`diff` call.

## what is well covered

- **H1 transfer estimator** (`transfer.rs`) — exemplary. Analytic single-pole
  spot-checks, sample-exact delay, coherence bounds, re/im round-trip, IR
  recovery. This is the model the rest of the tree should follow.
- **BS.1770-5 loudness** (`loudness.rs`) — Annex-1 coeffs locked to 1e-6, real
  Tech3341 conformance cases (1–4, 9) to ±0.1 LU, true-peak Annex-2 FIR, gating,
  LRA. Correct LKFS/dBTP designations.
- **CCIR-468 weighting network** — full Table-1 curve verified (the network, not
  the detector).
- **Reference-level / conversion layer** — scalar dBu (regression-safe),
  AES17-2020 §3.12 dBFS convention single-sourced and round-trip tested.
- **Farina sweep** — log-spaced harmonic offsets, sign/magnitude recovery,
  cubic-nonlinearity 3rd-harmonic detection.
